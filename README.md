# DragN's VV: Refueled

Adds a fueling system to [DragN's&nbsp;Valiant&nbsp;Vehicles](https://www.curseforge.com/minecraft/mc-mods/dragns-valiant-vehicles)

---

### Notable changes

- Smaller vehicles
- More realistic vehicle controls
- Fueling and battery system
- + 2 new items to go along with it
- On wall and entity collision mechanics
- Exhaust particles
- Many configurable parameters
- And much more
